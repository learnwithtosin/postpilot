Slicing & Indexing
Slicing and Indexing are operations we use to access and create/get elements within a sequence i.e: lists, sets, tuples and strings.

Indexing
Indexing allows us access a single element within a sequence by using its position. In Python, we use 0 based indexing instead of 1, so the first element starts from 0 to 1 and so forth, and we cn also use negative indexing which starts from the right hand side as -1.

syntax :sequence[index]
where the index starts from 0 in positive indexing or -1 in negative.

Slicing
Slicing extracts(gets) a new sequence (subset) from a bigger sequence of indices.

syntax:sequence[start:stop:step]

start: This is the starting index of our slice of a sequence which can either be 0 or a negative number depending on if it is positive or negative slicing.

stop: The ending index of our slice. That is where we want our new subset of the sequence to stop at.

step: The rate of progression of our slice. by default, this can be left empty. But we can if we wish to, make our subset have a step, let's say h, where h can be that our subset is every second member of our sequence, or every third member, etc. But note that no matter ourh, the subset must start from the very first element.

CSS: A Learner's Perspective.
CSS, short for Cascading Style Sheets, is the cornerstone of web design, allowing developers to style HTML elements and create visually appealing, responsive, and dynamic web pages. Here, I'll provide a walk through of what I've learnt so far in CSS, from basic concepts to more advanced concepts and techniques.

Understanding the Basics
CSS follows a simple rule-based syntax to style HTML elements. The three main ways to apply CSS are:

Inline CSS: Applied directly within an HTML element using the style attribute.
Internal CSS: Defined within a <style> tag inside the HTML document’s <head>.
External CSS: Stored in a separate .css file and linked to the HTML document.

Box Models
The CSS box model defines how elements are structured in a web page. It consists of four main parts:

Content: The actual text or image inside the element.
Padding: Space between the content and the border.
Border: The boundary surrounding the padding.
Margin: Space outside the border, separating elements.

CSS Grid
CSS Grid is a two-dimensional layout system ideal for structuring web pages. Example:

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}
Flexbox
Flexbox is a one-dimensional layout model used for arranging items in a row or column. Example:

.flex-container {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
Conclusion
Mastering CSS is essential for front-end developers to create elegant and functional web pages. By understanding these core principles and advanced techniques, you can build visually stunning and user-friendly websites.
