# Lessons: Tosin

Rules learned from edits to drafts and voice notes. `npm run voice` and `npm run draft` read this file and follow every lesson below.

Add each lesson in this format:

```
### Lesson N
Rule: what to do or avoid
Applies to: X, LinkedIn, or all posts
Why: the reason behind the rule
From edit: what was generated and what was changed
```
